## Setup Instructions

1. Create an OIDC Identity Provider in your AWS account (see docs/OIDC_SETUP.md)
2. Create an IAM role with the trust policy allowing GitHub Actions to assume it
3. Attach necessary IAM policies to the role for managing your 3-tier infrastructure (EC2, RDS, VPC, ALB)
4. Add the AWS_ROLE_ARN secret to your GitHub repository settings
5. Create a 'production' environment in GitHub with required reviewers for manual approval of applies
6. Update the AWS_REGION in the workflow if your infrastructure is not in us-east-1
7. Ensure your Terraform backend (S3) is properly configured for state storage

## How to Add Secrets

1. Go to your repository on GitHub
2. Click **Settings** → **Secrets and variables** → **Actions**
3. Click **New repository secret**
4. Add each secret listed above
