## Setup Instructions

1. Create the OIDC Identity Provider in AWS IAM (see docs/OIDC_SETUP.md)
2. Create an IAM Role with the trust policy for GitHub Actions OIDC
3. Attach necessary AWS permissions to the IAM role for Terraform operations
4. Add the required secrets to GitHub repository settings
5. Create a 'production' environment in GitHub with required reviewers for manual approval
6. Ensure PM2 is installed on your backend EC2 instance: `sudo npm install -g pm2`
7. Ensure your backend EC2 security group allows SSH (port 22) from GitHub Actions IPs
8. Test the pipeline by creating a PR or using workflow_dispatch
