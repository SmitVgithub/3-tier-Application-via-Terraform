## Setup Instructions

1. **Add Repository Secrets**: Go to Settings → Secrets and variables → Actions → Add `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`
2. **Create GitHub Environment**: Go to Settings → Environments → Create `staging` environment with required reviewers for manual approval
3. **Create Destroy Environment (Optional)**: Create `staging-destroy` environment with stricter approval for destroy operations
4. **Update AWS Region**: Modify `AWS_REGION` in the workflow if your infrastructure is not in `us-east-1`
5. **Verify S3 Backend**: Ensure your `backend.tf` is properly configured with your S3 bucket for state storage
6. **Test the Pipeline**: Create a PR with a minor change to test the plan output, then merge to trigger the apply with approval
