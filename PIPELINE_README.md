## Setup Instructions

1. Add AWS credentials (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION) to repository secrets at Settings > Secrets and variables > Actions
2. Merge the PR to enable the workflow
3. Create a pull request to see the Terraform plan output as a comment
4. Review security scan results from tfsec and Checkov in the Actions tab
5. Consider updating backend.tf to use remote state (S3 + DynamoDB) for team collaboration

## How to Add Secrets

1. Go to your repository on GitHub
2. Click **Settings** → **Secrets and variables** → **Actions**
3. Click **New repository secret**
4. Add each secret listed above
